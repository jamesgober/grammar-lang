# grammar-lang v1.0.0 — Stable API

**The API freeze.** v1.0.0 makes the parser generator delivered in 0.2.0 a
stable contract: the public surface and the behaviour documented for it — how
tokens are matched, how conflicts are settled, how productions are numbered,
what trees and errors report — will not change in a breaking way before 2.0.
The code is unchanged from 0.2.0; this release records the promise and what it
covers.

## What is grammar-lang?

A parser generator that runs at runtime, and the parser-generator core of the
`-lang` language-construction family. Describe a language's tokens, rules, and
operator precedence with a `Grammar`; `build` checks it and generates a
minimized DFA lexer and an LALR(1) parser; the `Parser` turns text into a
concrete syntax tree or drives your own semantic actions. The grammar is
plain data, so it can come from a schematic, a configuration file, or a test,
and a malformed grammar is an error value naming the problem.

## What's new in 1.0.0

### The stability promise

`docs/API.md#stability` now records exactly what 1.0 covers:

- **The frozen surface.** `Grammar`, `Parser`, `Actions`, `Production`,
  `Tree`, `Node`, `Kind`, `Tokens`, `GrammarError`, `ParseError`, and the
  `Span`/`Token`/`TokenKind` re-exports — every method, trait implementation,
  and auto trait listed there. `GrammarError` stays `#[non_exhaustive]`, so a
  minor release may add a variant.
- **The behavioural contract.** Longest match with literals before patterns
  and earlier declarations first; Bison-compatible precedence and conflict
  resolution, with every unsettled conflict an error; a grammar that builds
  keeps building; productions numbered in declaration order; actions in
  postorder; the tree's S-expression text form; errors at the first token that
  cannot continue, with an exact expected set; no `unsafe`, no panics, and
  every parse terminating.
- **What is not promised.** The wording of messages and `Debug` output,
  which conflict is reported when there are several, performance figures, and
  internal size limits — so they can keep improving in minor releases.
- **Dependencies and MSRV.** `token-lang` 1 and `diag-lang` 1 are public
  dependencies; a new major version of either means a new major version here.
  MSRV is 1.85, raised only in a minor release.

### How the contract was earned

The 0.2.0 surface was reviewed again before freezing, and kept as is: every
type has one job, the builder reads as one chain, and everything foreseeable —
error recovery, serialized tables, Unicode property classes — fits as
additive `1.x` work. The behaviour being promised is the behaviour that was
tested hardest:

- the generator against a canonical LR(1) construction merged by core, over
  random grammars;
- the parser, its first-error position, and its expected sets against an Earley
  recognizer on every short input;
- precedence and conflict resolution against GNU Bison 3.8.2 on thousands of
  random grammars, down to the exact sequence of reductions;
- token patterns, Unicode included, against a reference matcher.

```rust
use grammar_lang::Grammar;

// Bison:  %left '+' '-'   %left '*'   %precedence NEG
//         exp: exp '+' exp | exp '-' exp | exp '*' exp | '-' exp %prec NEG | NUM ;
let parser = Grammar::new()
    .literal("+")
    .literal("-")
    .literal("*")
    .pattern("NUM", "[0-9]+")
    .left(&["+", "-"])
    .left(&["*"])
    .left(&["NEG"])
    .rule("exp", &["exp", "+", "exp"])
    .rule("exp", &["exp", "-", "exp"])
    .rule("exp", &["exp", "*", "exp"])
    .rule("exp", &["-", "exp"])
    .prec("NEG")
    .rule("exp", &["NUM"])
    .build()?;
assert!(parser.parse("-1*2-3").is_ok());
# Ok::<(), grammar_lang::GrammarError>(())
```

## Breaking changes

**None.** The API is identical to 0.2.0; only the version and the
documentation changed.

## Verification

Run on Windows x86_64 and on Linux (WSL2 Ubuntu) from a copy outside the
workspace, on Rust stable and on the 1.85 MSRV:

```bash
cargo fmt --all -- --check
cargo clippy --all-targets -- -D warnings
cargo clippy --all-targets --all-features -- -D warnings
cargo clippy --all-targets --no-default-features -- -D warnings
cargo test
cargo test --all-features
cargo test --no-default-features
cargo build --examples
RUSTDOCFLAGS="-D warnings" cargo doc --no-deps --all-features
cargo +1.85 clippy --all-targets --all-features -- -D warnings
cargo +1.85 test --all-features
cargo deny check
cargo audit
cargo package
cargo bench --bench bench
```

All green. Counts at this tag, identical with default, all, and no default
features: 25 unit, 32 integration, and 5 property tests, plus 93 doctests.
macOS is covered by the CI matrix.

## What's next

Additive `1.x` work, none of it promised or blocking: error recovery for
multi-error parses, serializing a built `Parser`, Unicode property classes and
case-insensitive literals, and table compression for very large grammars.
